# Spec Delta

## Purpose

Gmail を取得元にするときに、どのメッセージを、どの値で、どれだけ安全に受信箱へ渡すかを定める。Claude はツールを呼ぶ役だけを担い、値はツールの返り値から取る。

## ADDED Requirements

### Requirement: 取得範囲

システムは、Gmail の受信トレイのメインタブに届いたメッセージだけを、取得元 `gmail` のメッセージとして受信箱に渡す（SHALL）。受信トレイにないメッセージ、およびソーシャル・プロモーション・新着・フォーラムのタブに分類されたメッセージは渡さない。

#### Scenario: メインタブのメッセージ
- **WHEN** 対象期間に、受信トレイのメインタブに届いたメッセージがある
- **THEN** そのメッセージを受信箱に渡す

#### Scenario: メインタブ以外のタブのメッセージ
- **WHEN** 取得結果に、プロモーションなどメインタブ以外のタブに分類されたメッセージが含まれる
- **THEN** そのメッセージは受信箱に渡さない

#### Scenario: 受信トレイにないメッセージ
- **WHEN** 取得結果に、受信トレイにない（アーカイブ済みなど）メッセージが含まれる
- **THEN** そのメッセージは受信箱に渡さない

### Requirement: 自分が送ったメッセージの除外

システムは、自分が送ったメッセージを受信箱に渡してはならない（MUST NOT）。スレッドを読むと自分の返信も含まれるため、送信済みのメッセージを取り除いてから渡す。

#### Scenario: スレッドに自分の返信が含まれる
- **WHEN** 取得したスレッドに、受信したメッセージと、自分が送ったメッセージがある
- **THEN** 受信したメッセージだけを受信箱に渡す

### Requirement: 読み取り専用の呼び出し

システムは、Gmail を読むために Claude CLI を呼ぶとき、Gmail の検索とスレッド・メッセージの読み取りのツールだけを許可し、送信・下書き・ラベル変更・既読化・ゴミ箱・迷惑メール・削除などの書き込み系ツールはすべて禁止する（SHALL）。

#### Scenario: 許可するツールは読み取り系だけ
- **WHEN** Gmail を読むための Claude CLI を起動する
- **THEN** 許可するツールの一覧には、Gmail の検索・スレッドの読み取り・メッセージの読み取りのツールだけが入っている

#### Scenario: 書き込み系ツールは禁止する
- **WHEN** Gmail を読むための Claude CLI を起動する
- **THEN** 禁止するツールの一覧に、Gmail の書き込み系ツールがすべて入っている

#### Scenario: 権限確認を飛ばさない
- **WHEN** Gmail を読むための Claude CLI を起動する
- **THEN** 権限確認をすべて飛ばすオプションは付けない

### Requirement: 会話の記録を残さない

システムは、Claude CLI を呼ぶとき、Claude CLI が会話の記録をディスクに保存しないように指定する（SHALL）。ツールの返り値に含まれる本文が、ユーザーデータ領域の外に残らないようにするため。

#### Scenario: 記録を保存しない指定を付ける
- **WHEN** Gmail を読むための Claude CLI を起動する
- **THEN** 会話の記録を保存しないオプションが付いている

### Requirement: 値はツールの返り値から取る

システムは、受信箱に渡すメッセージの値（ID、スレッド ID、送信者、件名、受信時刻、本文）を、Gmail のツールが返した値そのものから取る（SHALL）。モデルが最終的に出力した文章や JSON の値は使わない。

#### Scenario: モデルの出力とツールの返り値が違う
- **WHEN** モデルの最終出力に含まれる本文や送信者が、ツールの返り値と違う
- **THEN** 受信箱に渡す値は、ツールの返り値と同じである

#### Scenario: 受信時刻はツールの返り値から決める
- **WHEN** 対象期間かどうかを判断する
- **THEN** ツールが返したメッセージの受信時刻を使う

### Requirement: 取得手順の検証

システムは、1回の取得について次のすべてを満たさない場合、その回を失敗として扱う（SHALL）。

- 指定した検索条件で検索が行われている
- 指定した検索条件で見つかったスレッドを、すべて本文つきで読み取っている
- 指定した検索条件の結果に続きのページがあるときは、それも取得している

モデルが指定外の検索を追加で行っても、それだけでは失敗にしない。

#### Scenario: 指定した検索が行われていない
- **WHEN** 指定した検索条件での検索が1回も行われていない
- **THEN** その回を失敗として扱う

#### Scenario: 読み取っていないスレッドがある
- **WHEN** 指定した検索条件で見つかったスレッドのうち、読み取られていないものがある
- **THEN** その回を失敗として扱う

#### Scenario: 本文なしで読み取ったスレッドがある
- **WHEN** 指定した検索条件で見つかったスレッドを、本文を含まない形式でしか読み取っていない
- **THEN** その回を失敗として扱う

#### Scenario: 続きのページを読んでいない
- **WHEN** 指定した検索条件の結果に続きのページがあるのに、そのページを取得していない
- **THEN** その回を失敗として扱う

#### Scenario: 指定外の検索が追加で行われた
- **WHEN** 指定した検索に加えて、モデルが別の条件でも検索する
- **AND** 指定した検索条件の手順はすべて満たしている
- **THEN** その回を失敗にはしない

#### Scenario: 検索結果が0件
- **WHEN** 指定した検索条件での検索結果が0件である
- **THEN** その回は、新着0件の成功として扱う

### Requirement: ツールの返り値の検証

システムは、Gmail のツールの返り値が想定した形（ID、スレッド ID、受信時刻、ラベルが必ずある）に合わないとき、その回を失敗として扱う（SHALL）。

#### Scenario: 必須の項目が欠けている
- **WHEN** スレッドの読み取り結果のメッセージに、ID・スレッド ID・受信時刻・ラベルのいずれかがない
- **THEN** その回を失敗として扱う

#### Scenario: 返り値が JSON として読めない
- **WHEN** スレッドの読み取り結果が JSON として読めない
- **THEN** その回を失敗として扱う
